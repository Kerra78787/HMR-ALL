
# HMR-ALL Sources

This directory contains full working-tree mirrors of 12 upstream GitHub repositories.

## Synchronization

- All file types and folders are retained.
- No protocol filtering is applied.
- Only the current default branch is mirrored.
- Git history, branches, tags, and `.git` metadata are not copied.
- Git submodules are cloned recursively.
- Git LFS content is pulled when available.
- Failed downloads preserve the previous mirrored copy.
- GitHub Actions is configured to run every 5 minutes and can also be started manually.
