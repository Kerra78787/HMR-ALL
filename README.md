# HMR-ALL

Automatic mirror of 12 public proxy configuration sources.

## Supported protocols
- VLESS
- VMess
- Trojan

## Features
- Automatic update every 5 minutes
- Base64 subscription decoding
- Detects safely identifiable renamed source folders
- Removes deleted and outdated mirrored files
- Preserves previous data when a source update fails
- Keeps each source in a separate folder

## Sources
All mirrored TXT files are stored in the `Sources/` directory.

## Update
GitHub Actions → HMR-ALL Auto Update
